# Publicação SEO — 13/10/2026
A home pública é pré-renderizada a partir do próprio React durante o build Vercel. O HTML inclui o conteúdo visível e mantém scripts e estilos para navegação e formulários. A build falha se não houver conteúdo suficiente ou canonical correto. Lovable mantém seu processo anterior.
Links públicos, canonicals do proxy Vercel e feeds usam www.smartdent.com.br. O proxy Supabase preserva query parameters de originalPath. A função de Search Console descobre uma propriedade verificada de www ou do domínio e envia sitemap-index.xml; falhas continuam pendentes.
A home e o domínio público permanecem na Vercel. O mapeamento antigo Cloud Run de parametros não é usado como evidência de DNS ativo nem foi removido. Serviços GTM permanecem separados.
A pré-renderização integral das demais rotas e a verificação completa de dados estruturados precisam de avaliação por rota. Não há garantia de indexação ou pontuação 10/10.
