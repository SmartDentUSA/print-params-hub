- Promotional tables attach a price table independent of combos: an existing distributor list (default Loja Oficial), or one own `dealer_price_lists` row keyed by `promotional_table_id` (no distributor) seeded either from the Loja Oficial selling price (exclusive) or as an exact copy of another promotion's table (clone, previous items snapshotted first), edited with the shared DealerPriceTable; own lists never backfill the catalog or appear in distributor queries. Pending discount edits are flushed by "Salvar tabela" and the editor's own save republishes the PDF snapshot, because Agenda and Portal show only that PDF.
