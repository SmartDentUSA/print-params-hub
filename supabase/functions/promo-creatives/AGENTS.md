- Promotional table creatives: `promo-creatives` (admin only) creates one Drive folder per table under the campaign parent folder, uploads files there plus a `wa-media` copy, and generates/stores each creative's default WhatsApp template (`whatsapp_message`, AI body + fixed footer with `{cupom}`/`{validade_cupom}`/`{vendedor}`); the Agenda `crm-insercao` `creatives` action only fills that template with the server-resolved seller's coupon via `_shared/creative-message.ts` (no AI for sellers; a seller's own edit is stored per team member in `promotional_creative_seller_messages` through `creative_save_message`/`creative_reset_message`), so codes and dates stay exact and the message is defined once in the editor.
- Promotional table social posts: `promotional_tables.social_hashtags` (normalized, exact-tag match in `_shared/promo-social.ts`) selects published Instagram `social_posts`; each post's default WhatsApp template (Post Grupos summary prompt from `_shared/post-summary.ts` + post link + the creatives coupon footer) is generated once per table/post into `promotional_social_post_messages` (editor via `promo-creatives`, or lazily on Agenda open, bounded per request, never overwriting editor edits) and rendered per seller in `crm-insercao` `social_posts`, with seller edits in `promotional_social_seller_messages`; one template per post keeps sellers' AI cost and text consistent.
